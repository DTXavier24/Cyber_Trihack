STEP 1: LAUNCH APPLICATION
Run `Hogwarts_Library_Portal.exe` (or `python org/app.py`). The application 
starts a local Web Server on `http://127.0.0.1:5000/` and opens the portal in 
the user's browser.

STEP 2: INSPECT COOKIES
Open Browser Developer Tools (F12) -> Navigate to the "Application" or 
"Storage" tab -> Select "Cookies" -> `http://127.0.0.1:5000`.
Locate the `session` cookie. The default value is Base64 encoded:
  `cm9sZT1zdHVkZW50` -> Decodes to -> `role=student`

Modify the payload string from `role=student` to `role=headmaster`.
Base64 encode the updated string:
  `role=headmaster` -> Base64 -> `cm9sZT1oZWFkbWFzdGVy`

STEP 4: EXTRACTION

`cm9sZT1oZWFkbWFzdGVy` and refresh the page (F5).
The portal updates privilege state and renders the flag:
-> TriHack26{4l0h0m0r4_byp455_5ucc355}
